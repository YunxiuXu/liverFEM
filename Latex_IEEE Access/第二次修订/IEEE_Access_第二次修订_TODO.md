  - 论文正文（已写入，英文）：Physics updates occur approximately every 24 ms (~41.2 FPS). Between updates, the independent 1 kHz control thread retains the latest force command as its target (zero-order hold). This separates command output timing from simulation timing, maintaining a regular, slew-limited command stream despite variations in physics computation time. The 1 kHz rate governs the low-level actuator control loop, including the slew-limited PWM output and command timing. New force information becomes available at the simulation update rate of approximately 41.2 Hz. The force signal is further smoothed by the 10 ms low-pass filter described above.
